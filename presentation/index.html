2. The Problem Statement

Challenges in Traditional Employee Leave Systems

Manual Bottlenecks

Managers struggle with spreadsheet tracking, lost emails, and unverified leave balance calculations.

Conflicting Overlaps

Employees accidentally submit overlapping requests, causing team understaffing and scheduling conflicts.

Lack of Auditability

Rejections lack documented justification, leading to employee dissatisfaction and compliance risks.

3. The Solution: LeaveFlow

Unified 3D Platform with Automated Validation Engine

Real-Time Balance Engine

Instant balance deduction upon manager approval, zero delay, real-time sync across employee & manager portals.

Granular Half-Day Support

Full Day (1.0d), First Half (0.5d), and Second Half (0.5d) options with smart same-date overlap detection.

4. User Workflow Matrix

Role-Based Experience for Employees and Managers

Employee Workflow

  • View available balances (Annual, Casual, Sick)
  • Submit leave request with dates & reason
  • Select duration mode (Full/Half Day)
  • Track status (Pending, Approved, Rejected)

Manager Workflow

  • Review pending queue with full request context
  • Approve request (triggers auto balance deduction)
  • Reject request with mandatory feedback note
  • Inspect team-wide leave balance directory

6. Enforced Business Rules

14 Server-Validated Constraints Enforced

Date Integrity: Start date $\le$ End date & duration $> 0$.
Balance Cap: Requests exceeding available balance blocked.
Overlap Guard: Conflicting date overlaps automatically rejected.
Self-Approval Guard: Managers cannot approve own requests.
Immutability: Completed decisions cannot be modified.
Audit Note: Rejection requires mandatory explanation string.

9. AI Change Loop Implementation

Feature Extension: Half-Day Leave Support

Iterative Resolution Trajectory:

  1. Attempt 1: Extended schema for FIRST_HALF & SECOND_HALF (0.5 day math). Overlap engine blocked opposite half-days on same date.
  2. Analysis: Identified calendar date overlap engine needed half-day granularity awareness.
  3. Attempt 2: Updated overlap check logic to allow opposite half-days on same date while blocking identical half-days or full-day conflicts.
  4. Outcome: 100% test suite green across unit & E2E tests! Documented in docs/ai-change-loop.md.
